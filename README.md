# 你好,这里是 AI4Paper(爱为学术)

**做科研文献阅读与管理的工具:在 Zotero 里直接看期刊分区和影响因子,用 AI 辅助读论文、做笔记、写稿。**

官网:[ai4paper.pro](https://ai4paper.pro) · 使用文档:[ai4paper.pro/docs](https://ai4paper.pro/docs/)

## 能帮你做什么

- **在文献列表里直接看期刊分区和影响因子**,不用一篇篇去查
- **读英文论文更快**:划词翻译、术语解释、围绕一篇论文提问
- **把读过的东西留下来**:笔记、摘录,写稿时直接带进去
- **三种用法,同一个账号**:Zotero 插件、桌面版、网页工作台
